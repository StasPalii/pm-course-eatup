# EatUp

## 1. Назва
EatUp — сервіс попереднього замовлення страв у їдальні.

## 2. Проблема
Довгі черги під час перерв, через які студенти та викладачі не встигають пообідати. 

## 3. Аудиторія
Студенти та працівники університету з обмеженим часом на перерву, а також персонал їдальні.

## 4. Опис продукту
Вебзастосунок для перегляду актуального меню, оформлення замовлення та швидкого отримання їжі за допомогою QR-коду без очікування в загальній черзі.

## 5. Основні функції
- **Каталог:** перегляд меню з цінами.
- **Кошик:** вибір страв та оформлення замовлення.
- **QR-код:** генерація коду для швидкої видачі замовлення.
- **Адмін-панель:** керування меню та статусами замовлень для працівників їдальні.
