# План витрат та часу (Time and Cost Plan) - Проєкт EatUp

## 1. Вхідні параметри
* **Склад команди:** 3 фахівці (Backend, Frontend, QA)
* **Тривалість робочого дня:** 4 години/день
* **Вартість години роботи (Team cost):** $15/год
* **Contingency Reserve (Резерв на непередбачені витрати):** 10%
* **Management Reserve (Управлінський резерв):** 15%

## 2. Оцінка часу (Time Estimate) для v1.0-MVP
Загальна оцінка часу на реалізацію критичного функціоналу (Backlog + Subtasks) становить **120 годин** на всю команду.
* Час роботи одного спеціаліста: 40 годин (10 робочих днів по 4 години).
* Тривалість спринтів: 2 тижні (Sprint 1 + Sprint 2).

## 3. Розрахунок бюджету (Cost Estimate)
1. **Базова вартість розробки (Development Cost):**
   120 годин × $15 = **$1800**

2. **Резерв на ризики (Contingency Reserve - 10%):**
   $1800 × 0.10 = **$180**

3. **Базовий бюджет проєкту (Cost Baseline):**
   $1800 + $180 = **$1980**

4. **Управлінський резерв (Management Reserve - 15%):**
   $1980 × 0.15 = **$297**

## 4. Загальний бюджет (Total Project Budget)
* Total Budget = Cost Baseline + Management Reserve
* Total Budget = $1980 + $297 = **$2277**

**Висновок:** Для успішного релізу версії v1.0-MVP проєкту EatUp необхідно закласти бюджет у розмірі $2277 при загальних витратах часу у 120 робочих годин.
